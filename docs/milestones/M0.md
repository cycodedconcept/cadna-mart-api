## Limitations and follow-up

- GitHub-hosted CI cannot be executed locally; its workflow is provided but no remote push/run was performed. Local validation used MariaDB 10.4.28; CI specifies 10.11.
- npm audit still reports 10 dependency findings (7 moderate, 3 high): minimatch through TypeScript ESLint and deepmerge-ts through Prisma config. The production-only audit reports the three Prisma-chain findings. Critical Vitest/tinypool findings were removed by upgrading to Vitest 5.1.0. Remaining automatic fixes require incompatible dependency changes; evaluate a Prisma major migration and updated lint tooling separately. Validation passing is not a claim of a clean security audit.
- Prisma's package.json seed configuration emits a deprecation notice for version 7; it is supported by the selected version 6.
- Use current Node 22 LTS (tooling requires 22.12+); validated on Node 22.15.0. Package engines remains >=22 as requested.
- Rate limiting is in-memory and proxy trust is disabled; shared-store/proxy configuration belongs in deployment hardening.
- M1–M9 endpoint assignments are proposals until backend milestone scope and admin workflow details are agreed. Only health is implemented in M0.

The sandbox blocked registry access, local database sockets, test listeners and Prisma cache writes. These checks were rerun with approved access rather than skipped.
